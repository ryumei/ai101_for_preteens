## ねらい

「AI」という言葉で漠然と語られている技術のコンセプトを、子どもが自分で読んで理解できる形で説明します。
技術に触れること自体が目的ではなく、しくみを知ることで過度な信頼や誤解をせず、道具として使う心構えを持てるようにすることを目指しています。

## 内容

全17枚の説明スライドと、テーマごとの「やってみよう」クイズ4枚で構成しています。

- **しくみ** — 次の言葉を予測しているだけ／大量の文章から学んだ／たくさんの「ダイヤル」／考えてはいない、計算している
- **得意・不得意** — ことばは得意／でも万能じゃない／もっともらしい嘘をつく／まちがいも覚えている／答えの元は人間の誰かの意見
- **心構え** — 自分で確かめる／道具として使う（丸投げしない）／自分のことは入れない／大事なことは人に相談する／みんなでルールを決める（ガバナンス）

クイズはブラウザ内で完結し、回答はどこにも送信・保存されません。

## 使い方

`index.html`（各言語版は `en/`, `es/`, `fr/`, `ko/`, `zh-Hans/`, `zh-Hant/` 以下）をブラウザで開くだけです。reveal.js とフォントを同梱しているため、ネット接続なしで動作します。

## 保護者・先生向けガイド

- **対象・所要時間**: 小学校高学年（5〜6年生）が自分で読める内容です。全18枚＋クイズ4回で、通しで読むと15〜20分ほどです。
- **使い方**: 1人で読ませてもよいですし、授業や親子で一緒に画面を見ながら、区切りごとに感想を聞いてみるのもおすすめです。
- **一緒に話してみてほしいこと**
  - 最後のページの「まとめ」5点（確かめる・道具として使う・自分のことは入れない・人に相談する・みんなでルールを決める）
  - 「AIが変なことや怖いことを言ってきたら、大人に伝える」という約束（p.16）
  - 家庭や学校でAIを使うときの決まりごと（宿題での可否など）は、地域や学校によって異なります。このスライドの内容とあわせて、身近なルールも確認してください
- **注意点**
  - このクイズへの回答はどこにも送信・保存されません（ブラウザ内で完結）
  - 日本語版が原本で、それ以外の言語（English / Español / Français / 한국어 / 简体中文 / 繁體中文）は AI による機械翻訳のため、正確でない可能性があります
  - 分かりやすさを優先しているため、専門的には厳密でない説明が一部含まれます
