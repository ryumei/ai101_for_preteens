## ねらい

「AI」という言葉で漠然と語られている技術のコンセプトを、子どもが自分で読んで理解できる形で説明します。
技術に触れること自体が目的ではなく、しくみを知ることで過度な信頼や誤解をせず、道具として使う心構えを持てるようにすることを目指しています。

## 内容

全17枚の説明スライドと、テーマごとの「やってみよう」クイズ4枚で構成しています。

- **しくみ** — 次の言葉を予測しているだけ／大量の文章から学んだ／たくさんの「ダイヤル」／考えてはいない、計算している
- **得意・不得意** — ことばは得意／でも万能じゃない／もっともらしい嘘をつく／まちがいも覚えている／答えの元は人間の誰かの意見
- **心構え** — 自分で確かめる／道具として使う（丸投げしない）／自分のことは入れない／大事なことは人に相談する／みんなでルールを決める（ガバナンス）

クイズはブラウザ内で完結し、回答はどこにも送信・保存されません。

## 使い方

`index.html`（各言語版は `en/`, `es/`, `ko/`, `zh-Hans/`, `zh-Hant/` 以下）をブラウザで開くだけです。reveal.js とフォントを同梱しているため、ネット接続なしで動作します。
